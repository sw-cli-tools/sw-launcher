COR24 memory layouts across the language corpus

A visual companion to docs/survey/index.md. Thirteen repos, five distinct shapes, one common 16 MiB address space (0x000000 SRAM through 0xFFFFFF MMIO).

Generated as part of step 001-survey-repos in the sw-launcher Phase 0+1 saga. To serve locally: ./scripts/serve.sh (port 5264).

Pattern legend. A single-image-at-zero, UART-fed source. B runtime + image + patch. C nested interpreter with heap-limit patch. D multi-module composite image. E resident shell + paste-and-go.
Stack: COR24 EBR is always 3 KiB at 0xFEEC00..0xFEF7FF; MMIO is at 0xFF0000+. Diagrams omit them unless the repo touches their geometry.

sw-cor24-monitor E

Resident monitor + sws shell + program slots. Emulator preloads every binary; transfer of control happens in-emulator via mon_invoke_program trampoline (saves SP, calls program, longjmp-style return via svc_exit_impl). User cannot edit source -- only invoke pre-assembled binaries by name.

sw-cor24-script (sws) E
